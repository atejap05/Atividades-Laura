# Produção textual

Atividades voltadas à **elaboração de pequenos textos** pela criança — escrita e
desenvolvimento da expressão (não apenas marcar alternativas).

Ideias de propostas para esta pasta:

- **Escrita livre guiada:** a partir de uma imagem, tema ou início de história ("Era uma
  vez…"), a criança continua/cria o texto.
- **Reescrita e ordenação:** colocar frases em ordem, completar parágrafos, reescrever com
  outras palavras.
- **Bilhetes, listas e legendas:** gêneros curtos do cotidiano (bilhete, convite, lista,
  legenda de desenho).
- **Descrição:** descrever um objeto, animal ou personagem.

Siga o padrão A4 do repositório (ver [`../../CLAUDE.md`](../../CLAUDE.md) e o template
[`../_template-atividade-a4.html`](../_template-atividade-a4.html)): use blocos `.read-box`
para o estímulo e amplie as áreas de escrita — em vez de `.line` curta, use vários
`<span class="line">` empilhados ou um bloco pautado para o texto. Inclua um quadro de
critérios simples no gabarito (ex.: começa com letra maiúscula, usa ponto final, tem começo–
meio–fim) e, quando possível, a habilidade da BNCC de Língua Portuguesa correspondente.
